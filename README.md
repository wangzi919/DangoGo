## 專案概述

DangoGo 是一款專為日語學習者設計的現代化 Web 應用程式。透過直覺的羅馬字即時校驗、智慧錯題歸檔與雲端跨裝置同步，協助學習者擺脫死記硬背，高效建立假名肌肉記憶與字彙量。

## 核心功能

- **五十音盲打特訓**  
  完整涵蓋平假名、片假名、清音、濁音、半濁音與拗音。系統具備即時羅馬字容錯判定、連續答對累計（Streak）與標準日語語音朗讀（Web Speech API）。

- **智慧錯題收錄與強化**  
  自動記錄練習過程中答錯的假名或單字，統計錯誤頻次，並提供專項特訓模式，協助學習者針對薄弱項目集中消滅盲點。

- **自訂單字庫與隨堂測驗**  
  預設收錄核心單字與情境例句，支援使用者自由新增與維護個人專屬生詞庫，並可隨時啟動單字盲打隨機抽考。

- **跨平台虛擬日語鍵盤**  
  專為行動裝置或未安裝日文輸入法的桌面環境設計，支援點擊輸入，並可即時加入濁點、半濁點或切換拗音小字。

- **基礎文法解析**  
  整理常見核心助詞與例句對照，條理分明，便於在練習過程隨時查閱基本日語語法結構。

- **雲端資料同步**  
  深度整合 Supabase 雲端資料庫，單字筆記、錯題本與學習進度均支援跨裝置無縫同步，同時兼顧本機離線運作需求。

- **動態互動回饋**  
  結合吉祥物的狀態動效與成就視覺回饋，在連擊突破與作答過程中提供生動且溫和的學習陪伴。
